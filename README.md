# 栈闩工房

机关推箱子纯前端工房。不同种类的箱子触发对应踏板，踏板改变门与地板，记录步数并保存已完成关卡的最佳成绩。

## 长箱、插销与齿圈

旧的单格普通货箱仍按 Sokoban 规则直推一格。名为「插销与反向齿」的关卡加入了可绕固定插销摆动的长箱：

- 只有推到不在插销上的自由端才产生力矩，长箱完整扫过四分之一圈后落向新朝向。
- 扫掠使用连续多边形碰撞与保守推进，不只检查首尾姿态；首尾不重叠但中途相碰时仍会在第一处受阻角度停止，且不提交位置、不计步。
- 相邻齿圈按齿数反向传动；同一角度接入多个啮合/传动约束时会一起求解。传动比冲突或任一接触继续挤入障碍，都在该接触处停止。
- 多个接触点属于同一次原子推演，不会按箱子 `id`/箱号分别推动或重复计步。
- 方向按钮可悬停预览；黄红高亮边和右侧边列表标出第一处相碰的稳定边 ID，也可直接在画布上靠近该边拾取。
- 只有走满 90° 才提交所有啮合箱子的新角度，随后统一刷新踏板、门/地板、胜负与步数。重置关卡会从蓝图重新水化，因此固定插销和长箱的初始相对朝向会一起还原。

## 本地运行

```bash
npm install
npm run dev
```

类型检查与生产构建：

```bash
npm run typecheck
npm run build
```

## Docker

```bash
docker compose up --build
```
